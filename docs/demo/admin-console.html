操作列语义
查看＝读主档全列＋该 SN 变更流水（EP-010）；编辑＝只改 PROFILE 4 列＋maintain_*，一次 CAS；回收＝逻辑删 deleted=1，不是物理删。
为什么列表里有 version
后台乐观锁需要它随编辑请求回传；对外查询接口不返回 version/id/deleted/maintain_*/ext_json（字段白名单）。
时间列显示"未同步"
库内用哨兵值 1970-01-01 00:00:00 表示外部尚未推送，出口转 null，不把内部约定泄漏给使用方。
图片列
image_url 属对外白名单，是公网可读地址、不需要签名。空串＝建档时未填（显示"无图"）；本效果图离线打开，缩略图用按型号配色的本地占位图，真实地址见悬停提示与详情抽屉。
